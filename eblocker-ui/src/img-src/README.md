# eBlocker Logos with Numbers

The eBlocker 3, 4, etc. logos are created in OmniGraffle and exported to SVG.

How to create the next version:

* Hide layer _Numbers as Shapes_
* Show layer _Numbers as Text_
* Update texts to new version number
* Show layer _Numbers as Shapes_
* Remove old shapes
* Copy texts and paste them into shapes layer
* Select texts and convert them into shapes
* Hide layer _Numbers as Text_.

For exporting to SVG:

* Draw a selection frame around the logo to export
* Use _Selection_ as area to export
* Use transparency
* Switch margin off or set it to 0px.

Why use only shapes in SVG? The browser/OS might not have the right
font.
